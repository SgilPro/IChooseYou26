# 產品分析支線：分析框架與第一輪速覽

> 2026-11-13 建立。目的：把我們（I Choose You）對標的網站放在同一把尺上比較，知道「別人有什麼、沒有什麼、做得多好」，再決定我們要補什麼、要靠什麼不同。
> 這份是**框架加第一輪粗掃**，不是完整拆解。先前的 `research/line3-competitor-tools/`（12 個工具的拆解，重點在 Game Log 之後的路線）仍然有效；本支線的差別是加入 2026 年新出現的中文圈網站，並把比較做到「每個功能做得如何」。

**方法與限制**
- 2026-11-13 用瀏覽器各開一次首頁，再開 8 個子頁（PokéOmni 的參考隊伍、對戰模擬、每週趨勢；victorpoke 的選出推薦、隊伍探索；TrainerOps 的隊伍庫、工具總覽；Pikalytics 的 top teams）。

- 數字（隊伍數、賽事數）是當天頁面顯示的值。

## 2. 分析框架

框架分四層，由粗到細。第一層回答「有沒有」，第二層回答「做得如何」，第三層回答「所以誰強在哪」，第四層回答「我們怎麼辦」。

### 第一層：功能盤點（有沒有）

把功能分成七類，每一類底下列具體功能。每個網站在每個功能上標：● 有、△ 有但不完整、○ 未見、？ 無法判斷。

| 類別 | 具體功能 |
|---|---|
| A. 資料查詢 | 圖鑑、招式／特性／道具一覽、屬性相剋、速度線 |
| B. 對戰工具 | 傷害計算、速度比較、組隊器、對位／對戰模擬、選出推薦 |
| C. 環境情報 | 使用率、每週趨勢、賽事列表與結果、官方消息與活動日曆、規則更新 |
| D. 隊伍庫 | 賽事隊伍、玩家分享隊伍、影片來源隊伍、租借碼、配點公開、篩選（原型、包含／排除寶可夢） |
| E. 內容 | 文章／週報、教學指南、測驗 |
| F. 平台能力 | 帳號與雲端儲存、多語、通知或訂閱、分享連結 |
| G. 解釋與學習 | 隊伍思路說明、戰術定位、控速分析、對戰復盤 |

G 類是我們自己加的，因為這是我們目前唯一做得比別人多的地方，需要有一欄能被看見。

### 第二層：單一功能的深度評分（做得如何）

對每個「有」的功能，用六個面向各給 0 到 3 分，並寫下依據（看到什麼才給這個分數）。

| 面向 | 問的問題 | 0 分 | 3 分 |
|---|---|---|---|
| 1. 涵蓋與新鮮度 | 資料夠不夠多、多久更新 | 零星、看不出更新時間 | 涵蓋完整，且標明每週或每日更新 |
| 2. 正確與可查證 | 資料能不能追到來源 | 沒有來源 | 每筆都能連回賽事、影片或公式 |
| 3. 深度 | 只到「是什麼」，還是到「為什麼、怎麼用」 | 只有清單 | 有配置、理由、用法 |
| 4. 好不好用 | 新手幾步能得到答案 | 要自己摸索 | 一眼看懂，有引導 |
| 5. 在地化 | 繁中與台灣用語、官方譯名 | 沒有中文 | 繁中完整且譯名正確 |
| 6. 串接 | 能不能把結果一鍵帶到下一個功能 | 各功能孤立 | 隊伍可帶入計算、模擬、分享 |

評分表範本（之後每個要深入的功能填一張）：

| 功能 | 網站 | 涵蓋 | 可查證 | 深度 | 好用 | 在地化 | 串接 | 依據（看到什麼） |
|---|---|---|---|---|---|---|---|---|
| 隊伍庫 | （待填） | | | | | | | |

### 第三層：優劣勢摘要（誰強在哪）

每個網站寫三件事：最強的一點、最弱的一點、它的資料或流量從哪來（護城河）。

### 第四層：對我們的意義（怎麼辦）

每個功能歸到四格之一：
- **必備**：大家都有，沒有會被當成不完整。
- **差異化**：別人沒有或很弱，是我們要押的。
- **不做**：別人已經做得很好，我們連過去就好。
- **觀察**：還看不出價值。

### 3.2 各站優劣勢（初步印象）

| 網站 | 最強的一點 | 最弱的一點（這一輪看到的） | 資料從哪來 |
|---|---|---|---|
| PokéOmni | 功能最齊，而且互相串接：隊伍、對位模擬、速度、傷害在同一站。也是唯一把影片當隊伍來源的站 | 沒有文章與教學，偏工具，不解釋「為什麼」 | 賽事結果、影片、天梯 |
| TrainerOps | 情報最即時：每日簡報、週報、活動日曆、3626 支隊伍 | 對戰工具是標準配備，沒有對位模擬或選出推薦 | 賽事（數量最多）、官方線上賽、玩家分享 |
| victorpoke | 三語、有教學指南、有選出推薦、有玩家社群分享 | 傷害計算自己標 MVP；隊伍庫是玩家自行分享，品質不一 | 公開賽事統計、玩家投稿 |
| Pikalytics | 使用率的事實標準，跨世代，有測驗與文章 | 沒有中文；對 Champions 的在地資訊（租借碼、中文譯名）弱 | Showdown 與賽事資料 |
| Serebii | 資料最完整的百科，新聞最快 | 幾乎沒有對戰工具；資訊結構老舊 | 自行整理 |

### 3.3 對我們的意義（初步，待你確認）

**先說壞消息**：我們原本以為「把影片裡的隊伍整理成資料庫」是空白，但 PokéOmni 已經把影片列為隊伍來源（59 隊），而且它還有 848 隊的總量、租借碼與配點篩選。單純比隊伍數量與工具齊全度，我們贏不了。

**2026-11-13 補查**（見 `01-pokeomni-video-source.md`）：那 59 隊來自 25 個頻道的 38 支影片，以英文、日文為主，繁中只有 1 支，沒有 Fiske；而且只收配置，沒有講解。所以它和我們目前沒有內容重疊，我們的獨特性在「繁中、單一頻道收得深、有講解與分析」。

**還站得住的差異**（G 類）：
- 沒有任何一站解釋「這隊怎麼打」。我們有 Fiske 講解的脈絡、核心輸出、注意事項、評分，以及戰術定位標籤與控速分級。
- 沒有任何一站做逐回合復盤。

**四格歸類的初稿**：

| 歸類 | 功能 | 理由 |
|---|---|---|
| 必備 | 隊伍篩選（包含／排除、原型）、租借碼、分享連結 | 三個中文站都有，是隊伍庫的基本盤 |
| 差異化 | 隊伍思路與分析、戰術定位、控速分析、復盤 | 五站都沒有或很淺 |
| 不做（連過去） | 傷害計算、圖鑑、使用率、活動日曆 | 別人已成熟，重做沒有優勢 |
| 觀察 | 選出推薦、對位模擬、測驗、玩家投稿 | 有站在做，但價值與正確性還沒驗證 |
