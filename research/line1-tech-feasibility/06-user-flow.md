# 06 — 詳細使用者流程（User Flow）

## 0. 設計原則

- **半自動**：機器產草稿，使用者校正。明確設定使用者預期「這是輔助工具，不是 100% 正確」。
- **可隨時退出/重來**：擷取與處理皆可暫停、停止、重跑。
- **看得到對應截圖**：每個事件都連回縮圖，方便核對。

## 1. 主流程（Happy Path）

### Step 1 — 進入 App / 選擇來源
畫面提供三種輸入卡片：
- 📁 **上傳對戰影片**（MVP 首選）
- 📷 **即時擷取（OBS 虛擬攝影機 / 擷取卡）**（v1）
- 🖥 **分享螢幕／視窗／分頁**（v1.5；用於看直播）

並提示：第三方串流網址（YouTube）不支援直接讀取，請改用「分享分頁」。

### Step 2 — 設定（前置）
- 選**遊戲語言**（日 / 繁中 / 簡中 / 英）→ 決定載入的 OCR 模型 + 字典 + 句型樣板。
- 選**畫面版型 / 解析度預設**（用於 ROI 座標），或進入「ROI 校準」小步驟（見 Step 4）。
- （即時擷取）顯示授權說明。

### Step 3 — 授權 / 載入來源
- **影片檔**：選檔 → 建 objectURL → 載入 `<video>`，顯示時長與首格預覽。
- **即時擷取**：
  1. 請求攝影機權限（`getUserMedia`）。
  2. 授權後 `enumerateDevices()` 列出 videoinput（此時 label 才可見），讓使用者選「OBS Virtual Camera」。
  3. 顯示即時預覽。
- **螢幕分享**：呼叫 `getDisplayMedia()`，使用者在系統選單選來源 → 顯示預覽。

### Step 4 — ROI 校準（首次 / 可選）
- 在預覽畫面上疊一個可拖曳框，請使用者框出「底部訊息框」位置（其餘 ROI 可由比例推算）。
- 提供「常見版型」一鍵套用；校準結果可記住，下次免重設。
- 目的：提升 OCR 準確度、降低誤判。

### Step 5 — 開始擷取 / 處理
- **影片檔**：點「開始分析」→ 背景以設定間隔 seek+截圖 → 過濾 → OCR → 結構化。顯示進度條（已處理 X% / 已產生 N 個事件）。可暫停/取消。
- **即時擷取**：點「開始錄製分析」→ 邊看邊每秒採樣、即時過濾與 OCR、時間軸即時增長。可隨時「停止」。
- UI 顯示即時統計：採樣張數 / 關鍵影格數 / 已辨識事件數。

### Step 6 — 檢視與校正復盤（核心價值畫面）
- **時間軸 / 回合檢視**：依回合分組展開，每回合內依階段（換人→行動→結算）列事件。
- 每個事件卡片：縮圖 + 圖示（招式/特性/換人/狀態）+ 描述文字 + 信心標記。
- **低信心事件標黃**，提示核對；點擊可放大截圖、就地編輯文字/類型/歸屬回合，或刪除/新增事件。
- 可重新命名對戰、標記勝負、加備註。

### Step 7 — 儲存 / 匯出 / 分享
- MVP：存到本機（IndexedDB），可匯出 JSON / 純文字戰報 / 圖文。
- v1：登入後存雲端、產生分享連結。

## 2. 邊界情況（Edge Cases）

| 情況 | 處理 |
|---|---|
| 使用者拒絕攝影機/螢幕授權 | 顯示說明與重試按鈕，導向「改用影片檔」 |
| 選到第三方串流 URL 想直接讀 | 明確提示不支援，引導用「分享該分頁」 |
| OCR 信心普遍很低 | 提示「畫面可能太小/模糊」，建議調高解析度或重新校準 ROI |
| 影格抽取被 taint（誤用跨域來源） | 攔截並提示來源不支援截圖 |
| 找不到 OBS 虛擬攝影機 | 提示「請先在 OBS 啟動 Virtual Camera」並附教學連結 |
| 回合邊界漏抓 | 結構化後在 UI 允許手動「在此分割/合併回合」 |
| 同一事件被截到多張（打字動畫） | debounce 去重；UI 仍提供合併 |
| 即時擷取中分頁被切到背景 | 提示背景分頁可能降頻採樣，建議保持前景；或記錄掉格警告 |
| 處理中關閉分頁 | 即時擷取中途資料儘量階段性寫入 IndexedDB，重開可續看已產出部分 |
| 大影片檔（數十分鐘） | 分段處理 + 進度可恢復；警告 ffmpeg.wasm 路徑較慢 |
| iOS Safari | ffmpeg.wasm 多執行緒不可用；即時擷取體驗受限——MVP 標示「建議桌面 Chrome/Edge」 |

## 3. 分階段範圍（MVP → v1 → v2）

### MVP（驗證可行性與價值）
- 輸入：**本機影片檔**。
- 流程：定時截圖 → ROI/pHash 過濾 → 訊息框 **Tesseract.js OCR** → 字典比對 + 句型樣板 → FSM 分回合 → 可編輯時間軸 → 本機儲存/匯出。
- 語言：先支援 1～2 種（建議先做 OCR 較有把握者，依打樣決定）。
- 目標：證明「準確度夠用 + 規則覆蓋常見事件」。

### v1（即時 + 準確度升級）
- 加 **OBS 虛擬攝影機 / 擷取卡即時擷取**。
- OCR 視 MVP 結果改/加 **雲端 OCR（後端代理）**。
- 寶可夢/招式/特性字典完整化、自動分回合穩定化。
- 帳號 + 雲端儲存 + 分享連結。
- ROI 校準記憶、多語系擴充。

### v2（進階）
- 螢幕分享輸入（看直播）。
- HP 條比例 / 狀態圖示視覺辨識，交叉驗證 OCR。
- 隊伍預覽（雙方 6 隻）辨識、勝率/數據統計、跨場分析。
- 自訓遊戲字體 OCR 模型；可能評估 Electron/Tauri 桌面版以改善擷取與檔案存取。
