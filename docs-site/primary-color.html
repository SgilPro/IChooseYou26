水泥灰上的主色該選什麼

底色固定為水泥灰（背景 #E4E7EA、卡片 #EEF0F2）。logo 先不納入考量。下表的對比與色盲模擬都由這一頁的程式即時計算，不是手填。

結論

保留紫色相，微調為深靛 #4F3DB5。語意色已經佔掉紅（危險）、綠（成功）、藍（資訊）、橘（注意），主色最安全的位置就是剩下的紫色相。深靛在水泥灰上文字對比 6.3:1，白字按鈕約 8:1，在綠色盲與紅色盲模擬下與四個語意色的色差都不低於 10。

  • 為什麼不選紅：紅色與危險色在色盲下幾乎同色，主按鈕與刪除按鈕會被混淆。你也覺得 logo 紅太鮮豔，所以這條不用再糾結。
  • 為什麼不選青綠或藍：深青與成功綠、資訊藍色差只有 7 到 8；藍色與資訊藍重疊。
  • 為什麼不選梅紫、洋紅：看起來是同一個紫色家族，但在綠色盲下與危險紅的色差掉到 4 到 6，會混。
  • 墨黑是穩妥的備案：對比 13:1、與所有語意色至少差 18，缺點是沒有品牌個性，整個介面會偏冷硬。

主色色階 50 到 950（已套用到全站 tokens.css）

方案並排

對比與辨識度（即時計算）

WCAG 2.2：一般文字 4.5:1、大字與 UI 元件邊框 3:1。色差用 OKLab ΔE×100；低於 8 視為容易混淆。色盲模擬用 Machado 2009 矩陣（完全型）。

使用規則

  • 主色只做「主要動作」：主按鈕實底、連結、目前頁底線、焦點環。不用在狀態表達。
  • 狀態一律「圖示 + 文字 + 外框」：不靠顏色單獨傳達（WCAG 1.4.1）。危險按鈕用外框樣式，主按鈕用實底，形狀就不同。
  • 焦點環：2px 主色環加外側 4px 底色間隔，在水泥灰三層底色上對比皆高於 3:1。
  • 淡底標籤：主色 10% 混入卡片色當底、主色當字與外框，文字對比仍高於 4.5:1（頁面上的「控速」「雨天」標籤即是）。
  • 屬性標籤沿用外框淡底深字：火屬性紅與紫色主色不會相鄰衝突。
