原始資料表

對應 Notion 的三張表：隊伍（team）→ 寶可夢實體（team member，class vs. instance 的 instance）→ 寶可夢圖鑑類別（species，class）。直接從 JSON 攤平，欄位名稱即 schema 欄位。下載：teams.json · teams.csv · videos.json · videos.csv

teams（隊伍）
team_members（寶可夢實體 · instance）
species（寶可夢圖鑑類別 · class）
videos（影片主表，Champions 對戰影片）

資料來源：data/channels/fiskepokemon/videos.json、teams.json（由 yt-dlp 抓 metadata 與字幕、ffmpeg 抽隊伍介紹段影格、Claude 讀畫面與字幕填表、再以 PokeAPI 名稱對照與 Lv.50 能力值公式機械驗證）。寶可夢圖像來自 PokeAPI sprites 的官方插畫（著作權屬 Nintendo / Creatures / GAME FREAK / The Pokémon Company，本站為非官方粉絲網站）。努力值：Champions 隊伍以「能力點」顯示（總和 66、單項 32），朱紫隊伍為 0–252 制。
