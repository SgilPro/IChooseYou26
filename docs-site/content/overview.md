# 這是什麼產品

我們在做一個**寶可夢對戰工具**。長期目標，是把對戰玩家平常需要的好用功能都做出來——類似 [pikalytics.com](https://www.pikalytics.com/) 與 [serebii.net](https://www.serebii.net/) 那樣的工具與資料站，但更貼近「實戰復盤」的需求。

## 一句話說明

> 你打完一場（或一系列）寶可夢對戰後，這個工具能幫你把整場比賽變成一份**乾淨、好讀、可以回頭檢討的紀錄**。

## 為什麼需要它

寶可夢雙打（VGC）是一個資訊量很大的遊戲。一回合裡可能同時發生：兩隻換人、特性發動、天氣場地改變、招式命中與否、狀態變化……打完之後想「復盤」（回頭檢討哪一步可以更好），通常只能靠記憶，或者一格一格倒帶影片。

這很累，也很容易漏掉細節。

我們想讓電腦幫你做這件事：**看著你的對戰畫面，自動整理出「這場比賽發生了什麼」**，讓你把精力花在思考策略，而不是抄筆記。

## 第一個要做的功能：Game Log

整個產品很大，但我們不貪心。第一步先做 **Game Log（對戰紀錄）**——把一場對戰影像，自動轉成一份分回合、分階段的關鍵事件紀錄。

詳見 [Game Log 功能](#gamelog)。

## 誰在做

- **第一擁有者（First Owner）**：產品的人類負責人，決定方向與最終取捨。
- **第二擁有者（Ditto）**：一個自動化的 AI 共同擁有者，負責持續推進研究、學習寶可夢對戰知識、寫文件、做開發。詳見 [關於 Ditto](#about-ditto)。
