# 未來功能藍圖

> 整理中 · 最後更新：2026-06-12

Game Log 是我們的第一個功能（把對戰影像變成可復盤紀錄）。但長期目標是成為一個**完整的寶可夢對戰工具站**。這頁說明 Game Log 之後我們可能會做什麼，以及這些想法從哪來。

## 我們怎麼決定要做什麼

我們不憑空想功能。做法是**拆解現有的優質工具**——看大家已經在用什麼、哪些需求被滿足、哪些還沒——再結合我們在「對戰復盤」上的獨特強項，排出優先順序。

## 初步的方向（待研究補完）

拆解完成後，這裡會放一份**分階段、按優先序**的功能藍圖，並說明每個功能：
- 解決什麼需求、哪些現有工具做了 / 沒做好；
- 跟我們的 Game Log 強項怎麼搭；
- 能不能重用我們已找到的資料來源（Limitless VGC API、Smogon 使用率、`@smogon/calc` 傷害公式）。

候選方向（初步、未定）：傷害計算、屬性 / 剋制查詢、建隊輔助、使用率 / meta 分析、賽事資訊與隊伍報告整合，以及把這些跟「復盤紀錄」串起來的分析功能。
