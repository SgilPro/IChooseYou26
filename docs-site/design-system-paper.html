再生紙米色Design System v2

再生紙的淺米色底，略灰、不偏黃橘；primary 以色彩學與 a11y 檢驗後選定。三種元件風格：fluid glass、石板、手寫紙。

01 · 底色與色彩理論

底色：三個明度候選

再生紙的米色特徵是「偏灰的暖色」：色相約 92°（黃偏綠一點點的米），彩度低（C* 約 5–8）。太黃或太橘會像牛皮紙或泛黃舊報紙；太白則失去紙感。明度 L* 控制在 89–96。

推薦與原因

推薦 P2 #F0EBE0（L* 93.2、C* 5.9）。理由：

  • P1（L* 95.9）是奶油白，和 surface 幾乎一樣亮，紙感與層次都薄。
  • P3（L* 89.3、C* 8.1）彩度已高出 P2 約 40%，大面積使用就是牛皮紙／泛黃感，你說要避免的「髒黃橘」；同時三級文字 #6A6254 在 P3 只有 4.57:1，幾乎壓線。
  • P2 的色相 92° 偏黃綠而非橘（橘約 60–70°），所以是「灰米」而非「奶茶／杏色」，更像未漂白的再生紙。

中性色階

色階的色相與底色同族（微量染色），避免「灰得髒」。每格顯示對推薦底色的對比值。

表面層級

四層由低到高：page → surface → raised → overlay，另有 sunken 作凹陷區。亮度逐層往白靠近，陰影逐層加深；不靠色相切換層級。

02 · Primary 候選比較

Primary 色：用對比、色相關係與色盲模擬檢驗

所有數字由本頁 JS 即時計算：WCAG 2.x 相對亮度對比（文字 ≥ 4.5:1，大字與 UI ≥ 3:1）；色盲模擬使用 Machado et al. (2009) 嚴重度 1.0 的矩陣（線性 RGB 空間），距離用 CIE Lab 的 ΔE76（≥30 清楚、15–30 需文字或圖示輔助、<15 易混淆；此門檻為經驗值）。

推薦與理由

推薦 P1 寶可夢靛藍 #2D45B8，搭配 皮卡丘黃 #F5B800 作暖色點綴（手寫紙風格的螢光筆、膠帶用）。

  • 對比：白字 7.91:1、文字色對底 6.65:1、UI 邊框 6.65:1，是四個候選中餘裕最大的。
  • 色盲：紅綠色盲模擬下與底色 ΔE 86+，與最近語意色（info）ΔE 38，仍清楚。藍色與米色分處藍／黃軸兩端，色盲看起來仍是「冷」對「暖」。
  • 辨識度：靛藍就是寶可夢（紅藍版）的藍，品牌連結強；也不與 danger／warn／success 撞色。
  • 備選：P3 靛紫（5.72／6.52:1，ΔE 37）同樣通過，若要延續第一版的紫色，在米色底上完全可行，只是與藍相比少了與底色的互補張力。

回答你的假設：「暖底配冷色／冷底配暖色」

結論：在再生紙米色上「成立」，且有 a11y 以外的支持。

  • 色彩學：底色色相 92°（黃綠米），互補約在 272° 附近（藍紫）。P1 靛藍 230°、P3 紫 251° 都落在互補帶，最「對比」且穩；對比越清楚，文字色對底的明度差也越好控制。
  • a11y：同樣只看明度，所以暖色（P4 磚橘 4.68:1）也能過關；但 P4 與米色同屬暖區（類比），視覺上較「糊」成一片，且在紅綠色盲下與 warn ΔE 僅 1–6、與 danger 正常視覺下 ΔE 15，會與警告色混。
  • 例外：並非所有冷色都好用：P2 深青（hue 187°）雖是冷色且通過對比，但與我們的 info 語意色（青藍）在色盲模擬下 ΔE 只有 14，容易混淆；若選青色就得把 info 改成別的色相。結論：要選「藍到紫」這段，而不是「青到綠」。

05 · 元件風格

三種元件風格，同一組元件

卡片、主要／次要按鈕、tag／chip、輸入框／下拉、分頁籤、Reg Set 徽章、評分條、tooltip。互動元件可實際點擊／聚焦／hover。

風格 1 · Fluid glass（淺色）

適合首頁 hero、浮動工具列、對話框、篩選抽屜等「疊在內容或背景之上」的層；強調輕盈與現代感。
不適合大量文字的資料表、長篇分析（半透明底會讓對比隨背景浮動）；低階裝置 blur 耗效能；不支援 backdrop-filter 時退為不透明（已實作 @supports 退路）。Apple HIG 對 Liquid Glass 的提醒同樣是：材質應用在導覽／控制層，內容層保持可讀。

風格 2 · 石板（slate / stone）

適合「戰術板」感的區塊：隊伍分析、對戰要點、成就／排行榜；與寶可夢對戰「擺陣」的主題契合，亮色屬性標籤在深石面上特別醒目。
不適合全站大面積使用（在淺色主題裡會變成一塊塊深色島嶼，視覺很重）；粉筆黃用在小字時要確認對比；噪點紋理在高對比螢幕上可能偏粗。

風格 3 · 手寫紙（筆記本）

適合玩家筆記、對戰心得、隊伍「備忘」區；親切、有個人頻道風格，與影片頻道的「教學筆記」調性相近。
不適合密集數據（手寫字體小字閱讀性差、橫線會干擾表格）；整頁使用易顯得幼稚；字體需載入 Iansui（約數 MB 的中文字型，已用 Google Fonts 分段載入，仍需 font-display:swap 與系統楷體退路）。
