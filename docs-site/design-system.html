I Choose You Design System

寶可夢雙打學習工具站台目前實際使用的視覺 token 與元件。這份文件是 UI 調整時的單一對照表，不是新設計。

version v0.1 (WIP)last update 2026-11-11source docs-site/tokens.css
Overview

這份文件是什麼

站台是純靜態頁（GitHub Pages），各頁 CSS 寫在頁面內，共同的色彩由 tokens.css 提供。這裡把各頁實際用到的值整理在一處，方便對照、找出不一致，也方便日後換風格。

目前狀態：全站已採用淺色（水泥灰＋深靛）主題，token 單一來源為 docs-site/tokens.css（舊變數名保留別名）。附錄中的三個候選（v1 深色玻璃、水泥灰、再生紙）是當初的調查，其中水泥灰方向已被採用，其餘保留作參考。本頁的色票由 tokens.css 即時讀取，對比值依 WCAG 2.x 公式當場計算，不會與實站脫節。
已知落差：元件的 CSS 目前散在各頁（teams／team／roles／matches），尚無共用元件檔；角色標籤三組色與 tooltip 底色是寫死的十六進位值，不在 token 內。下方「待修問題」列出整理後的清單。

Foundations

Color

水泥灰中性底＋深靛主色（OKLCH 色相 283°）。對比值為「該色對其標示底色」的 WCAG 比值，徽章：AAA ≥ 7、AA ≥ 4.5、AA Lg ≥ 3（僅限大字或非文字）、其餘 Fail。

誤用警示：主色 --primary-400 以下（含 400）不可當文字或白字底；--primary-500 白字僅 AA Lg。文字請用 --primary-text（#4F3DB5）或 700 以上。

重要組合（前景 / 背景）

組合樣本前景背景比值等級

「非文字」類（邊框、角色標籤外框）以 3:1 為門檻，等級欄以此判斷。

角色標籤三組色（寫死於 team.html／roles.html）

屬性色（assets/types/colors.json）

來自 52poke 屬性標籤底色（2026-11-09 取得），目前僅作資料；網站尚未用它做大面積底色。小圖示在 assets/types/icons/symbol/<id>.png，道具圖示在 assets/items/（皆為 PokeAPI sprites，屬任天堂等公司，公開前需加非官方聲明，見 assets/types/README.md）。下列對比為白字於其上，多數不通過，所以不能直接當實底配白字。

6. 戰術定位標籤

黃＝輸出、藍＝戰術、綠＝輔助。實線外框＝手動確認，虛線外框＝由招式／特性推斷。三組色皆為淺底＋深字＋2px 同色系外框。差異：圖示為示意用的簡化形狀（實站每個角色有自己的線條圖示）。

7. 自製 tooltip

性格：固執（攻擊提升、特攻下降）

tooltip.js：任何帶 title 或 data-tip 的元素 hover／focus 立即顯示，底 #1B1F24、白字 12.5px 600、圓角 8、帶小箭頭，Esc 關閉，捲動時隱藏。本頁已載入同一支腳本，移到這裡試試。

8. Toolbar 與標籤列收合

共 42 隊
全部Reg M-AChampions雨天晴天沙暴順風戲法空間

9. 顯示／隱藏切換

實線＝手動確認、虛線＝由招式／特性推斷

用 aria-pressed 表達狀態：開啟時邊框與字變 --accent。實站以 body 的 class（hide-roles）控制內容顯示。可實際點擊試試。
