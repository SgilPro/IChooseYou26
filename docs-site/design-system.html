Design System 研究總覽

水泥灰主色決策頁：對比與色盲辨識的即時計算（建議深靛 #4F3DB5）

資料密集的寶可夢雙打工具（隊伍卡、屬性標籤、評分條、按鈕）該長什麼樣子。這一頁把先前三份預覽（深色玻璃、水泥灰、再生紙）與新增的 11 個方向放在同一處，並附上待決問題與建議。

建議前三名

1. Radix Colors + shadcn 風（中性 slate + 靛色）

MIT、12 階色階系統化、淺深色對應完整。每個屬性色都能拿「第 3 階做底、第 11 階做字」，剛好就是「外框 + 淡底」的標籤做法，能解決紅／水／超能力當實底對比不足的問題。

2. GitHub Primer 風（密度與表格元件）

MIT、以 14px 為基準，label、counter、progress 都是為資料密集設計。半徑 6px、色彩克制，最適合隊伍分析區。可直接借它的 token 命名與間距階。

3. 再生紙（既有方案）＋ Radix 色階補強

辨識度最高、最不像一般工具站；手寫字體只用在標題與註記。以 Radix 的屬性色階取代自訂顏色，可兼顧個性與對比。

選擇邏輯

  • 屬性標籤一律採「外框 + 淡底 + 深字」（outline-tint），不用實底，才能全部通過 4.5:1 對比。
  • 授權：優先 MIT／Apache-2.0／OFL；Atlassian 與 GOV.UK 品牌資產有使用限制，只借概念不借資產。
  • Pokémon Champions、遊戲內 UI 與官方圖示屬任天堂／Game Freak 等公司所有，本站一律只用 CSS 自繪，不複製任何官方素材。
  • 評分條與控速 Level 要以「數字 + 形狀」雙重編碼，不能只靠顏色。

待決問題

  1. 屬性標籤是否改成外框 + 淡底（outline-tint）？紅（火）、藍（水）、粉（超能力）等顏色當實底配白字，對比低於 4.5:1，不通過。建議全面改 outline-tint，實底只留給大面積裝飾。
  2. 石板（slate）風格只用在分析區嗎？深色石板質感很適合隊伍分析、評分與控速這類「儀表」區，但全站套用會與淺色主體衝突。傾向僅限分析區使用。
  3. 警示色（warn）要不要更偏黃？目前偏棕橘（#8F5300），在淺底對比夠，但不像「警告」。可改成較黃的底色加深色字（例如 #FFF3C4 底 + #6B4A00 字），維持對比又更直覺。

以上三題來自水泥灰／再生紙兩份預覽的審視，尚未決定；新增方向的研究結果（尤其 Radix 色階）可作為決策依據。
