IChooseYou26 Design System

寶可夢色彩 × 液態玻璃（fluid glass）。以精靈球與皮卡丘為色彩原點，透過半透明面板、背景模糊與細亮邊，讓資料密集的隊伍頁依舊輕盈、好讀。

01設計原則

內容優先於裝飾

玻璃是容器，不是主角。文字對比永遠先於透明感，必要時加深填色。

色彩有語意

藍＝行動、黃＝品牌與高亮、紅＝強調／危險、屬性色只用在屬性。不混用。

層次靠模糊與亮邊

用 blur 強度分級（sm / md / lg）與細亮邊表示高度，而非厚重陰影。

優雅退化

不支援 backdrop-filter 就用不透明底；偏好減少動態就停掉背景流動。

手機先行

375px 無橫向捲動，觸控目標至少 44px，六隻寶可夢卡片可 3×2 → 2×3 → 1×6。

02Design tokens

點擊任何色票或變數名即可複製（例如 var(--c-primary) 的變數名 --c-primary）。切換上方主題可檢視深淺色版本。

主色組 Brand

選色理由：以寶可夢 logo 與精靈球為原點。primary 藍 #3B4CCA（logo 描邊藍）用於可點擊行動，與白字對比約 7.5:1，也是三色中最「冷靜」、適合大面積的一個； secondary 黃 #FFCB05（logo 黃）用於品牌標記、Reg Set 徽章與高亮，必須配深色字； accent 紅 #E3350D（精靈球紅）只做強調與警示，避免與屬性「火」的 #e62829 混淆而刻意偏橘。 深色模式把藍與紅提亮（#8E9BFF / #FF6A45）以維持在深底上的對比，黃色維持不變。

每種屬性顯示三種用法：實心標籤（自動選黑／白字）、描邊＋淡底標籤（文字用一般文字色，最穩）、色條。比值為「標籤上文字 vs 色底」與「色塊 vs 玻璃面板」（非文字元件需 ≥ 3:1）。

06對比與無障礙檢查

以 JS 即時計算：玻璃填色先疊在頁面底色上，再取「最壞情況」（疊在黃／藍／紅 aurora 色塊 40% 之上）。切換主題後自動重算。需 ≥ 4.5:1（大字／非文字元件 ≥ 3:1）。

焦點樣式

用 Tab 鍵走訪：所有互動元件有 3px 焦點環（淺色＝藍、深色＝黃），offset 2px。

減少動態與退路

  • prefers-reduced-motion：aurora 流動與轉場停用。目前偵測：—
  • backdrop-filter：—；不支援時 .glass 使用 --glass-fallback 不透明底。
  • 觸控目標 ≥ 44px；Tabs 支援鍵盤；狀態不單靠顏色（徽章皆有文字）。
