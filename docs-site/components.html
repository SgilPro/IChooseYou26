風格調查：哪一套適合我們

我們現在的設計語言是：水泥灰的中性底、單一主色（深靛）、細邊框、8 到 14px 圓角、很淡的陰影、資料密度高。下表是我對幾套常見設計系統的比對，「適合度」是對照這個語言所做的判斷。

風格視覺特徵和我們的搭配度結論
shadcn/ui
ui.shadcn.com		中性灰階表面、1px 細邊框、圓角 6 到 10px、陰影極淡、單一主色只用在重點上。最接近。它的「中性底加一個主色」和我們的水泥灰加深靛是同一種結構，元件尺寸（32／36／40px 高）也適合資料密集的列表。採用為主要參考
Radix（Primitives 與 Themes）
radix-ui.com		以互動與無障礙規範見長：鍵盤操作、焦點管理、彈出層的定位與進出場動畫。我們不用 React，所以不拿它的程式，只照它的行為規範做（下拉選單的鍵盤操作、Esc、打字搜尋）。採用為行為參考
GitHub Primer
primer.style		資訊密度高、標籤與計數徽章很成熟、對比穩。標籤（label）的做法值得借：淺底、有色邊、深色字。我們的語意色 chip 就是這個做法。借標籤做法
Vercel Geist
vercel.com/geist		黑白極簡、對比極高、圓角小、幾乎沒有陰影。很乾淨，但近乎無色，和我們有主色、有寶可夢屬性色的畫面相比太冷。只借動畫節奏
Linear 風格
linear.app		細膩的微動畫、滑動的選取指示、緊湊的控制項。沒有公開的設計系統可依循，但「滑動指示塊」的分頁動畫正是我們 pill 導覽要的效果。借分頁動畫
Material 3
m3.material.io		大圓角、色調表面、明顯的狀態層與波紋。辨識度太強，會讓站看起來像 Android 應用；控制項偏大，不利資料密度。不採用
Fluent 2
fluent2.microsoft.design		柔和陰影、4px 圓角、偏企業工具感。可用但沒有比 shadcn 更貼近，且風格聯想到 Office。不採用
新粗獷主義（neobrutalism）粗黑框、硬陰影、高飽和色塊。很有個性，適合活動頁；和目前細邊框的資料介面衝突。不採用

以上是我依各系統公開文件的印象所做的整理，沒有逐條回頭核對原文。我們只參考視覺與行為，沒有複製任何一套的程式碼或素材；之前較完整的 11 個方向調查在 附錄。

Button

五種樣式、三種尺寸。一個畫面只放一顆 primary，其他用 soft 或 outline。

樣式
尺寸
含圖示 連結也可以用
狀態 
<button class="ui-btn">儲存隊伍</button>
<button class="ui-btn soft sm">加入收藏</button>      <!-- 樣式：soft／outline／ghost／danger；尺寸：sm／lg -->
<button class="ui-btn" aria-busy="true">儲存中</button>  <!-- 載入中：自動出現轉圈並擋住點擊 -->

Icon button

只有圖示的按鈕。一定要寫 aria-label，並建議加 data-tip，滑鼠移上去才知道它做什麼。

樣式
尺寸
可切換 
<button class="ui-icon-btn ghost" aria-label="更多" data-tip="更多"><svg …/></button>
<!-- 樣式：ghost／soft／primary；形狀：round；尺寸：sm／lg；可切換：aria-pressed="true|false" -->

Select 與下拉選單

原生的 <select> 加上 data-ui-select 就會換成自製的下拉選單。原生 select 仍留在頁面裡當資料來源，所以表單送出、change 事件、用程式設定 .value 都照常運作。

目前規則組：全部

鍵盤：Enter、空白鍵或上下鍵開啟；上下鍵移動、Home／End 跳到頭尾；Enter 選取；Esc 關閉；直接打字會跳到開頭相符的選項。空間不夠時選單會改往上開。

<select data-ui-select aria-label="規則組">
  <option value="">全部</option>
  <optgroup label="Champions"><option>M-C</option></optgroup>
</select>
<!-- 動態插入的 select：window.UI.select(el)。選項事後增減會自動重建。 -->

Tooltip

沿用站上已有的 tooltip.js：任何元素寫 data-tip（或 title）就有，hover 或鍵盤 focus 立刻出現，不改游標，Esc 可關閉。

M-C 長文字與換行 
<button class="ui-btn" data-tip="說明文字">…</button>   <!-- 頁面要載入 tooltip.js -->

Tags／Chips

同一個 class 有三種用法：靜態標籤、可切換的篩選 chip、可移除的 chip。語意色一律是淺底、有色邊、深色字，不靠顏色單獨傳達意思。

<span class="ui-chip success">已驗證</span>

Menu tabs（pill）

保留現在的膠囊外型，動畫改成：實心指示塊會「滑」到新的選項，帶一點點回彈；滑鼠移到別的選項時，有一塊淡色預覽跟著移動。開啟「減少動態效果」的人不會看到滑動。

網站導覽（連結）

  <button role="tab" aria-selected="true" aria-controls="p1">隊伍資訊</button>
  <button role="tab" aria-selected="false" aria-controls="p2">隊伍分析</button>

所有 class 都以 ui- 開頭，不會和各頁既有樣式相撞。目前已套用到實際頁面的有：全站頁首的 pill 導覽（滑動指示塊）、隊伍列表的規則組與排序下拉選單。其餘頁面還是原本各自的寫法，之後逐步換過來。
