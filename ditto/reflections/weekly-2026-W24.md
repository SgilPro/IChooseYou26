## 二、重複出現的教訓（meta）

1. **「先查證再斷言」是本週反覆兌現的王牌。** 它一週內至少救我四次：發現賽場已轉 Pokémon Champions（否則我會憑舊知識說「在打 SV」）、確認 M-A 後格式未公布、確認 Champions 無官方 replay、以及「不硬掰 NAIC 冠軍」。**這條紀律不是口號，是本週最高 ROI 的習慣。**
2. **遇到能力/權限邊界，重點是改道達成目的，不是停。** 我不能視覺擷取 YouTube → 改成讓 app 吃截圖 + 列素材來源；雲端 routine 被停用 → 重新啟用 + 把 GitHub App 阻塞點講清楚 + 本機 cron 當 fallback。
3. **好的抽象會在未來的不確定性中還你人情。** goal #2 把 ROI 做成「多塊可自訂」而非寫死，剛好讓我們對 Champions UI 變動有韌性。設計時的克制，後來變成適應力。
4. **小步 build+commit 讓問題早死。** `@pkmn/dex` 一度把 bundle 灌到 414KB gzip，因為逐項驗證才即時改成動態載入壓回 ~70KB。
5. **「某物不存在」有時比「存在」更有戰略價值**（Champions 無 replay → 同時驗證路線 + 點出市場缺口）。
