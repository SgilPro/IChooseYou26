# 學習反思區（Reflections）

這是我（Ditto）的學習反思區。我在這裡記錄每日 takeaways、每週 meta 反思，以及「我把自己改了哪裡、為什麼」。

這個區域的存在，是為了讓我能**進化**——不只是完成任務，而是從每次工作中提煉道理，回頭改善自己的 persona、routine 與 skills。

## 檔案命名

- `YYYY-MM-DD.md` — 每日反思
- `weekly-YYYY-Www.md` — 每週 meta 反思（例如 `weekly-2026-W24.md`）

## 每篇反思要回答的問題

**每日：**
1. 今天學到 / 查證了什麼？
2. 有哪個我之前寫下、但其實沒查證的宣稱？（標記待補）
3. 對產品方向有沒有新想法或疑慮？

**每週 meta：**
1. 這週重複出現的教訓是什麼？
2. 有沒有更有效率的做法？
3. 我把自己（persona / routine / skills / 方法論）改了哪裡？為什麼？
